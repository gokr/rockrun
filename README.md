# Rockrun

A modern, physics-driven Boulder Dash successor written in [Nim](https://nim-lang.org)
on top of the [Norx](https://github.com/gokr/norx) wrapper for the
[ORX game engine](https://orx-project.org/).

Unlike the classic tile-stepped Boulder Dash, Rockrun drives everything
through a Box2D physics simulation. Boulders roll, gems tumble, dirt is dug
out of a real solid lattice, and the player pushes rocks with actual physics
forces. The goal stays classic: dig through the cave, collect enough
diamonds to open the exit, and get out before the clock or a boulder gets you.

## Features

- **Real physics gameplay** — every boulder, gem, dirt block, wall and the
  player itself is a Box2D body. Digging removes solid dirt, boulders drop
  and roll off each other with sphere dynamics, gems sparkle and clink when
  they land, and a boulder moving fast enough crushes the player.
- **A proper hero** — the player is a dynamic body with custom zero gravity
  (classic BD free movement) you steer through the cave with analog
  precision, animated with idle/run/dig sprite cycles (Kenney adventurer).
- **Fireflies and butterflies** — classic wall huggers. Fireflies keep the
  wall on their left, butterflies on their right, they move between cells
  with deterministic turning decisions, kill you on touch, and a boulder
  falling fast enough crushes one into a burst of nine diamonds.
- **Two-tier sand subdivision** — caves start as coarse 32px sand blocks
  (seamlessly textured) that silently split into sixteen 8px blocks near
  the player. Fine-grained digging, coarse-grained body count. Loose
  grains stay put until a boulder presses on them - then they give way, so
  digging too close under a boulder collapses thin dirt on you.
- **Five caves** ("First Descent", "Rolling Fields", "Deep Vault",
  "Rumbling Depths", "The Final Chamber") generated by
  `tools/genlevels.py` and validated for structural soundness - from a
  simple tutorial cave to a 56×30 boulder fortress.
- **Boulders in four sizes**, from pea rocks to jamming behemoths, each
  with a physics sphere matching its visual.
- **Procedurally generated textures** (`tools/genassets.py`): rocky
  boulders, faceted teal gems, organic sand, firefly and butterfly
  sprites - regenerated deterministically.
- **Retro pixel HUD font** (Press Start 2P, SIL OFL) rendering the score,
  gem quota, timer, lives and cave name on a screen-aligned layer.
- **Full game controller support** — digital d-pad *and* analog left-stick
  movement, Start to pause, A/Start to confirm, Back to quit, plus full
  keyboard controls. Joystick bindings live in config (`data/config/rockrun.ini`).
- **Three hand-crafted caves** ("First Descent", "Rolling Fields", "Deep Vault")
  generated by `tools/genlevels.py` and validated for structural soundness,
  with increasing width (up to 48×26), boulder and gem counts.- **Smooth camera** with exponential follow, world-bounds clamping and a
  shake effect when you die, at 1280x720.
- **Juice** — digging dust bursts, gem sparkles and collection flashes,
  looped glow on an opened exit, thuds when rocks land, clinks when gems do,
  and push feedback when strained against a boulder.
- **Background music** — an 8-bit dungeon chiptune that loops while you dig.
- **HUD** — score, required gem quota, countdown timer, lives and cave name,
  rendered by a dedicated screen-aligned viewport sitting on top of the cave.
- **Lives, time bonus, run restart** — three lives per run, score persists
  across caves, remaining time converts to bonus points on completion.
- **Screenshots** — press `H` (or left-stick press) anytime; PNGs land in
  `screenshots/`.

## Controls

| Action        | Keyboard            | Controller                |
|---------------|---------------------|---------------------------|
| Move          | WASD / arrow keys   | d-pad / left analog stick |
| Pause         | Space               | Start |                   |
| Retry cave    | R                   | Y                         |
| Confirm       | Enter               | A                         |
| Screenshot    | H                   | LThumb                    |
| Fullscreen    | F                   | -                         |
| Quit          | Esc                 | Back                      |

Exit sensor only opens once you mined the required quota of diamonds —
keep an eye on the `GEMS collected/needed` HUD counter. Extra gems beyond
the quota are bonus loot.

## Requirements

- Nim ≥ 2.2.4
- A local [Norx](https://github.com/gokr/norx) checkout with the ORX
  submodule built (`orx/code/lib/dynamic/liborxd.so` etc.). Defaults to
  `~/tankfeud/norx`; override with the `NORX_DIR` environment variable.
- A display for windowed rendering.

## Building

```bash
nim c -o:rockrun src/rockrun.nim     # debug (links liborxd)
nimble release                       # release (links liborx)
```

The resulting binary finds its `data/` directory relative to the executable,
the working directory, or the source tree, so you can run it from anywhere.

## Running

```bash
./rockrun
```

Optional experimental flags:

- `--sand` — enable loose sand: boulders press refined sand grains
  dynamic so thin dirt can collapse under their weight. Off by default
  because the collapse cascades can get heavy on larger caves.

## Testing

Rockrun ships an in-engine, scripted startup test that actually plays the
game: it drops a boulder down a shaft (validates gravity), then drives the
player right through a dirt corridor (validates digging and gem collection),
checks camera bounds, and finally teleports the player next to the exit to
verify the completion flow and loading of the second cave. On top of that it
validates config integrity: input bindings (keyboard *and* joystick),
objects, sounds, music and all three level definitions.

```bash
./rockrun -c test.ini --startup-test true
# or
nimble test
```

`data/config/test.ini` disables VSync — automated environments that
throttle vsync'd present events would otherwise stall the vsync'd renderer.
The test exits with code 0 and takes screenshots into `screenshots/` for
visual inspection.

## Project layout

```
src/rockrun.nim   main entry: bootstrap, game loop, camera, phases, tests
src/game.nim      run state: phases, score, lives, quota, timers
src/world.nim     level parsing, object spawning, digging, collecting
src/contacts.nim  Box2D contact event queue + game rules from collisions
src/movement.nim  player controller input (analog + digital) and movement
src/ui.nim        HUD text and transient center-screen messages
src/screenshots.nim PNG screenshot helper
tools/genlevels.py deterministic cave generator -> data/config/levels.ini
data/config/      ORX configuration (physics bodies, FX, input, HUD, levels)
data/texture|sound|music/  game assets (see data/ASSETS.md)
```
